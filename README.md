# Jaymark N. Matas — Portfolio

A responsive one-page portfolio built with HTML, CSS, and vanilla JavaScript.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a modern browser. For the best experience, use VS Code with the Live Server extension.

## Personalize before publishing
- **Profile photo:** Replace the portrait URL in the `.profile-frame img` element in `index.html` with your own image file, e.g. `images/jaymark.jpg`.
- **Email:** Replace `jaymarkmatas@example.com` in both `mailto:` links and the visible text with your real Gmail address.
- **Facebook:** Replace the Facebook profile URL and display name with your own.
- **Mobile:** Replace `+63 900 000 0000` and the `tel:` link with your actual number.
- **Projects:** The three cards are concept examples. Update their titles, descriptions, and image URLs to match your actual work.

The portfolio uses online Google Fonts and Unsplash images, so those assets require an internet connection. The rest of the site is plain HTML/CSS/JavaScript.
